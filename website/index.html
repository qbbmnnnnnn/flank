功能

来不及整理的，先放在手边

没有文件夹，没有标签体系，没有同步冲突。只有一块屏幕边缘，和随时可以取下的纸。

边缘便签栏 · 三态收纳

Rest 只留一条纸边；指针靠近进入 Fan，便签按距离浮起；点击后 Expanded 展开成完整卡片。移开就收回边缘。

马上来

速记 Quick Capture

任意应用里按全局快捷键唤起面板，输入停止即自动保存。Esc 收起。误删了？10 秒内可以撤销。

Markdown 与勾选任务

标题、列表、引用、行内代码、待办都支持。勾选框可直接点击切换，Markdown 原文无损保存。

本地加密 · 滚动备份

正文以 AES-GCM 加密写入本地 SQLite，配合滚动备份与故障恢复。没有笔记服务器，也没有数据上传。

马上来

导入导出 · Mac 迁移

支持 .stickies v2 导入与导出，MD / TXT 互转。固定状态不会从 Mac 导入，导入摘要会明确提示。

随手排序 · 保持顺手

按住纸边，上下拖动。把常用的放在前面，让便签的顺序跟上你的工作节奏。

隐私

数据留在你的电脑里

Flank 没有账号体系，也没有笔记服务器。它唯一需要的网络请求，是检查应用更新——你可以随时关掉。

  • 正文加密AES-GCM 加密后写入本地数据库；标题、颜色、时间等元数据明文存储，便于搜索与排序。
  • 无遥测不统计你的输入，不上传崩溃日志中的正文内容。
  • 边界透明本地加密保护正文，不代表整台电脑的访问防护。导入导出功能正在准备中。

常见问题

你大概会问

和 Windows 自带的 Sticky Notes 有什么不同？

Sticky Notes 更像一个独立的笔记窗口。Flank 常驻在屏幕边缘：不抢占任务栏，不遮挡当前工作，用一次快捷键或一次指针靠近就能取用，用完自动收起。此外 Flank 提供正文本地加密。

需要联网或者注册账号吗？

不需要。Flank 没有账号、没有云同步、没有笔记服务器。只有在检查应用更新时才会联网，这项也可以关闭。

可以从 macOS 版迁移数据吗？

即将支持。在 macOS 版导出 .stickies 文件后，Windows 版可以直接导入。需要注意：当前格式不包含“固定”状态，导入摘要会明确提示这一点。

支持哪些系统版本？

Windows 10 22H2 与 Windows 11，x64 架构。支持中文输入法。

便签数据存在哪里？

存在系统应用数据目录下的本地 SQLite 数据库中，正文加密。卸载时你可以先导出备份，再决定是否删除数据目录。

把便签栏，装到屏幕边缘

下载后它会自动住进系统托盘。第一次使用时，把指针移到屏幕右侧边缘，它就在那里。
