# 通用设置实现与验收

## 范围

保留简体中文 / English、跟随系统 / 浅色 / 深色、登录时启动 FLANK、关闭主窗口时后台运行 / 退出 FLANK。通用页移除快捷键宣传卡片；保留原有其他分类及已隐藏的数据与隐私代码。

## 交互说明

- 启动：先从原生 SQLite 设置读取，再挂载各窗口。主窗口初始隐藏，在前端就绪后显示；`--background` 登录启动不显示主窗口。
- 保存：控件变化立即加入应用级串行队列，按字段提交；原生端串行合并到最新设置，避免旧窗口整份设置覆盖新值。设置页面卸载不销毁保存队列。
- 成功：应用已确认的设置、更新状态提示，并向全部窗口广播。新窗口独立加载同一份持久设置。
- 失败：保留 / 重新读取已确认状态，恢复控件并提示错误；失败不会阻塞后续保存。读取失败时禁用表单并提供重试，不能用默认值覆盖原设置。
- 关闭：自定义关闭按钮及 Alt+F4 均由原生截获，等待前端设置队列完成后按保存的关闭策略隐藏主窗口或退出进程。保存失败已回退，不会让窗口无法关闭。
- 登录启动：调用 Windows 原生自启动插件，只有系统操作成功后才写数据库；数据库失败则恢复此前系统开关。重新启动时恢复已保存的登录启动偏好，读取设置时核对实际系统状态。
- 语言：Vue 文案函数与共享状态响应更新；托盘菜单同步切换。用户便签标题 / 正文不翻译；内置使用指南属于应用文案。
- 主题：文档语义颜色变量响应已保存主题；仅系统模式监听并应用操作系统深浅色变化。原有彩色便签纸张保持不变。
- 无障碍：主题使用 `aria-pressed`，状态提示使用 live region，设置弹层含对话框语义、Tab 循环、Escape 关闭与焦点恢复。

## 动效说明

此次不新增进场或装饰动画。保存成功后语言 / 主题直接切换，业务状态不依赖动画。保留已有过渡及全局 reduced-motion 降级。

## 数据边界

- 桌面版：SQLite 为持久化来源；旧设置缺少 theme 时默认 system。语言仅支持 zh-CN / en-US，旧的不支持语言回退简体中文。
- 浏览器预览：使用独立 localStorage 键 `flank-app-settings` 验证持久化；跨标签页由 storage 事件同步。登录启动开关禁用，避免假装浏览器可配置 Windows。
- 新增自动化覆盖：旧数据迁移、数据库关闭重开、连续保存、卸载后队列排空、写失败回退与重试、读取失败恢复、原生事件与启动快照竞争、系统主题响应、中英文与用户内容隔离。

## 尚需桌面人工验收

本轮没有注销 Windows，也没有停止当前运行的旧版 FLANK 进程。实际登录启动、原生托盘唤回、Alt+F4 的后台 / 退出两种策略，以及多 WebView 的原生广播，需在重启开发版 / 新构建后人工验收。浏览器测试不视为这些系统行为的实测证明。
